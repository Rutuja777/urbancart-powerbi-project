# urbancart-powerbi-project



\# FMCG Sales Analytics - Power BI



\## Project Overview



This project is an end-to-end Power BI analytics project based on FMCG sales data.



The goal is to analyze sales performance, customers, products, regions, and business operations using Power BI.



\## Technologies



\- Power BI

\- Power Query

\- DAX

\- SQL

\- GitHub
